AI 聚合网关

把 Android 手机变成一台私有的 AI 模型聚合服务器：把手机上已经登录的多家 AI 账号统一翻译成标准 OpenAI 协议，暴露在本机 http://127.0.0.1:8790/v1，任何支持 OpenAI 协议的客户端都能直接用。

最新 v2.38.8 12 个版本 Android 8.0+（minSdk 26） 包名 dev.aigw.app Kotlin · Compose

它解决什么问题

from ARCHITECTURE.md

手机里装着 Trae、WorkBuddy、Antigravity、ChatGPT、Loomy、小浣熊等服务的账号，它们的客户端协议各不相同，大多数无法直接在第三方工具里使用。

网关在本机起一个 HTTP 服务，把这些账号的额度集中到同一个 OpenAI 兼容端点：客户端只认一个 baseUrl 和一个密钥，背后由网关负责选号、刷新凭证、失败切换下一个供应商。

POST /v1/chat/completions
{
  "model": "gemini-3.8-flash",
  "messages": [{"role": "user", "content": "你好"}]
}

支持的上游账号

1 个网关 · 多个供应商

Trae

trae

WebView 回调登录，走 SOLO 私有 SSE 协议，流内上报计费。

WorkBuddy

codebuddy

设备授权码登录，上游只接受流式请求，支持签到与成长中心。

Antigravity

antigravity

OAuth 回环登录，Gemini 风格命名空间，凭证刷新按临期窗口严格限频。

ChatGPT（Codex）

chatgpt / codex

Responses 协议，按订阅额度转发。

Loomy

loomy

手机短信登录；鉴权失败以 200 + 业务码返回，需要单独判定。

小浣熊

raccoon

网页授权码回调，对话走 v2 LiteLLM 层，支持积分余额查询。

自定义供应商

custom:<key>

自己填 baseUrl 与 API Key，接入其他标准 OpenAI 接口。

主要能力

  • OpenAI 兼容入口：/v1/chat/completions、/v1/models，支持 Bearer、x-goog-api-key、?key= 三种鉴权写法。
  • 模型路由与故障切换：同一模型可配首选路由与多个备用路由，账号失败自动换号、换供应商。
  • 账号池：多账号统一管理，请求前按剩余额度与状态挑号，凭证刷新集中在一处。
  • 本地加密存储：账号与密钥存放在 EncryptedSharedPreferences，卸载即失效。
  • 前台服务保活：锁屏或切后台后端口仍有进程监听，看门狗负责重启引擎。
  • 客户端零改造：Cherry Studio、Cline、Continue、curl 等只要支持 OpenAI 协议即可接入。

快速开始

01安装

下载 APK 安装到手机（Android 8.0 及以上）。

02登录上游账号

在应用内逐个登录 Trae / WorkBuddy / Antigravity 等账号，账号存在本机。

03客户端接入

把 baseUrl 填成 http://手机IP:8790/v1，密钥用应用内生成的客户端密钥。

安装包由 fork 自动构建，签名与上游不同：覆盖安装前需先卸载旧包。应用内更新已指向本仓库。
